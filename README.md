# Смотрим вместе

Расширение для Chrome и других браузеров на Chromium: создаёт комнату просмотра YouTube, синхронизирует паузы и перемотку, показывает состояние буфера участников и даёт общий чат. Поддерживаются стандартные видео, Shorts, прямые эфиры, мобильные ссылки, embed-страницы и ссылки формата `/v/`.

## Установка расширения

1. [Скачайте ZIP расширения](https://raw.githubusercontent.com/Kurillin/rasshirenie-dlya-sovmestnogo-prosmotra/main/watch-together-extension.zip) и распакуйте его.
2. Откройте `chrome://extensions` в Chrome/Chromium или `edge://extensions` в Edge и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку с `manifest.json`.
4. Откройте видео на YouTube и нажмите **Смотреть вместе** в правом нижнем углу.
5. Создайте комнату или введите код друга. Друзьям нужно установить то же расширение и открыть то же видео.

Открытую панель можно переместить, перетащив её за шапку.
Через кнопку **«Поделиться»** в шапке можно отправить приглашение установить расширение или ссылку на видео, выбранное автором комнаты.

Расширение рассчитано на сервер `https://ext.namalkin.site/watch-together/api`.

## Сервер

Сервер использует Python, SQLite и Docker; база комнаты хранится в Docker volume. API доступен только через локальный порт, а публичные запросы идут через HTTPS и Nginx.

```powershell
cd server
docker compose up -d --build
docker compose run --rm watch-together python -m unittest discover -s tests
```

Тесты адаптера YouTube и проверки обновлений находятся в `tests/`. Запускайте Node.js команду `node --test tests/*.test.cjs` из корня репозитория.

Расширение проверяет GitHub Releases и показывает уведомление, если опубликована версия новее установленной. Если опубликованных релизов пока нет, уведомление не появится. Чтобы выпустить обновление, увеличьте `version` в `extension/manifest.json`, пересоберите ZIP и создайте GitHub Release с соответствующим тегом `vX.Y.Z`, приложив `watch-together-extension.zip`. Проверка выполняется не чаще одного раза в 6 часов; её можно запустить вручную в панели расширения. Уведомление ведёт на страницу релиза — установленное вручную распакованное расширение Chrome автоматически не заменяет.

Для нового хоста настройте TLS reverse proxy на `/watch-together/api/`, проксирующий запросы на `http://127.0.0.1:8787/api/`, и укажите адрес сервера в `extension/background.js` и `extension/manifest.json`.

Код комнаты — это секретный ключ доступа к комнате. Рассылайте его только участникам; не публикуйте его открыто.
